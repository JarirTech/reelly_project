# QA Automation Framework – Reelly.io

## Overview

This project was completed during my QA Automation internship at Reelly.io. The objective was to build and enhance an automated UI testing framework for a real estate web application using Selenium WebDriver, Python, and Behave (BDD).

Throughout the internship, I implemented automated functional tests, cross-browser execution, cloud testing, reporting, and mobile web testing while following Agile workflows and managing tasks in Jira.

---

## Project Objectives

- Automate UI test scenarios using Selenium WebDriver
- Implement Behavior-Driven Development (BDD) with Behave
- Execute tests across multiple browsers
- Configure headless browser execution
- Integrate BrowserStack for cloud testing
- Generate professional Allure test reports
- Validate responsive behavior on mobile web
- Track tasks using Jira Agile boards
